# DeFi Dashboard

Дашборд для одной задачи: видеть состав портфеля, риск позиции в лендинге и
экономику «занял стейблы → зафармил» без Excel и ручных подсчётов.

## Запуск

```bash
cd ~/projects/defi-dashboard
./.venv/Scripts/python -m streamlit run app.py
```

Откроется http://localhost:8501

## Структура

```
defi-dashboard/
├─ app.py                 # единственная страница: вёрстка и вывод
├─ requirements.txt       # streamlit, pandas, requests
├─ .streamlit/
│  └─ config.toml         # тёмная тема, порт, отключена телеметрия
└─ src/
   ├─ config.py           # тестовый портфель, параметры Aave, пороги риска
   ├─ data.py             # загрузка данных (пока заглушка + чтение CSV)
   ├─ metrics.py          # доли, HF, дистанция до ликвидации, карри, пыль
   └─ __init__.py
```

Разделение простое: **config — что считаем, data — откуда берём, metrics — как
считаем, app — как показываем**. Чтобы поменять источник данных, трогаем только
`data.py`; чтобы поменять формулы — только `metrics.py`; `app.py` остаётся
вёрсткой.

## Что уже считается

- общая стоимость и доли каждой позиции;
- сумма по кластерам (мейджоры, veTokenomics, L2, стейблы, мемы);
- долг как % от залога: `LT / HF`;
- дистанция до ликвидации: `1 − 1/HF`, и до рабочих уровней HF 1.5 / 1.4;
- чистый карри: `доходность фарма − ставка займа`;
- «пыль» — позиции дешевле $100;
- предупреждения при концентрации > 40%, стейблах < 10%, HF < 1.5 и
  карри < 5 п.п. (пороги в `src/config.py`).

## Как подключить реальные данные

1. **Цены и количества** — CoinGecko (`/simple/price`) или CoinMarketCap API.
   Складываем в DataFrame с колонками `token, cluster, chain, value`.
2. **Позиция в Aave** — subgraph Aave v3 (Arbitrum) или RPC-вызов
   `getUserAccountData`: оттуда приходят `healthFactor`,
   `totalCollateralBase`, `totalDebtBase`. Тогда HF и LT перестают быть ручными.
3. **Доходности пулов** — DeFiLlama Yields API (`yields.llama.fi/pools`),
   фильтр по цепи и токену.
4. **CSV как промежуточный вариант** — `load_positions_from_csv()` уже готов:
   удобно вести портфель руками и не ждать API.

## Идеи для второй страницы

- история HF и дистанции до ликвидации по дням;
- калькулятор «что будет с HF, если ETH −20%» (сейчас это считается, но не
  отображается графиком);
- таблица «кто платит холдерам»: механизм, порог участия, выплата, дата.
